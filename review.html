审核规则

  • 任何人都可以匿名提交城市数据修改或新建城市（JSON 由系统做结构与数值校验）。
  • 提交说明、完整数据、差异对比与审核结果对所有访客公开；联系方式仅管理员可见。
  • 管理员通过后，覆盖数据立即对全站生效（优先于内置数据），所有访客刷新页面即可使用。
  • 管理员可随时回滚到内置数据或任意历史版本；每次回滚同样记录在本页。

管理员登录

请输入 Netlify 站点环境变量 ADMIN_TOKEN 的值。 口令只保存在当前浏览器标签页（sessionStorage），关闭标签页后自动失效。

管理员口令
服务端未读取到 ADMIN_TOKEN

管理员登录要求 Netlify Function 在运行时能读到该环境变量。请按以下步骤检查：

  1. Netlify → Project configuration → Environment variables
  2. 新增 ADMIN_TOKEN，值用足够长的随机字符串
  3. Scopes 勾选 Functions（只勾 Builds 时函数读不到）
  4. 保存后 重新部署（Deploys → Trigger deploy → Deploy site）
  5. 回到本页点「重新检测配置」
通过口令后，审核按钮才会出现在记录卡片上。
